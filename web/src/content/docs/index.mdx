Un curso gratuito para aprender backend desde cero: lo que pasa detrás de cada web y cada app, de los cables de internet a los agentes de IA. Es para cualquiera: no hace falta saber backend ni programar para empezar, porque cada concepto se explica desde el principio, con ejemplos que puedes probar tú.

## Aunque no quieras dedicarte al backend

Las primeras fases explican la web por dentro: cómo viajan los datos por internet, cómo se maneja un servidor desde la terminal y cómo se hablan el navegador y el servidor con HTTP. Eso le sirve a cualquiera que trabaje con la web, no solo a quien escribe backend.

- **Si haces frontend,** entenderás qué pasa después de cada `fetch` y por qué a veces falla.
- **Si diseñas o trabajas en producto,** sabrás de qué habla tu equipo técnico.
- **Si tienes curiosidad,** sabrás qué ocurre de verdad cuando abres una web.

## Cada lección tiene algo práctico

- **Pruébalo en tu terminal:** ejercicios guiados con herramientas reales como `curl`, `dig` o `nc`.
- **Playgrounds:** herramientas reales dentro de la web, como una base de datos o criptografía, funcionando en tu navegador.
- **Laboratorios:** simulaciones paso a paso para lo más difícil de ver: HTTP, DNS, TCP y Docker.

Los playgrounds y laboratorios que ya están publicados, todos juntos, en [playgrounds](/playgrounds/).

## Temario

El curso se escribe mientras se aprende, y las fases se publican una a una. Tienes el detalle en el [temario](/roadmap/).
