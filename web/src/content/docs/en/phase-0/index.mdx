Every time you open a website, or an app on your phone loads data, a lot happens before the response arrives. Your device finds out where the server is, opens a connection, encrypts it, sends the request and waits. This phase is about all of that. You won't write any code yet: you'll understand the ground everything else is built on.

Even if backend isn't your goal, this phase is still for you. It's the web under the hood: what your browser does every day without you seeing it. If you do frontend, for example, you'll understand what happens to every request you send, and why it sometimes takes a while or fails.

## What you will learn

By the end of this phase you'll be able to explain, step by step, what happens from the moment you type a URL into the browser until the page appears. Along the way you'll see:

- What the backend is and how it differs from the frontend.
- What a client is, what a server is, and why a server is nothing more than a program waiting.
- What a protocol is and why the internet works in layers.
- How two computers find each other: IP addresses, ports, NAT and routing.
- Why TCP is reliable and UDP is fast.
- How `google.com` turns into an IP address.
- What the HTTPS padlock really protects.

## Before you start: the terminal

Many lessons have a **Try it in your terminal** block with commands you can run on your computer. Seeing things with your own eyes is the best way to make them stick. You don't need to know how to use the <Term id="terminal">terminal</Term>; we'll cover it in depth in Phase 1. For now, all you need is to open it, paste a command and press Enter.

### 1. Open the terminal

- **macOS:** press <kbd>Cmd</kbd> + <kbd>Space</kbd>, type “Terminal” and press Enter.
- **Linux:** look for “Terminal” in your applications. On many distributions you can also open it with <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>T</kbd>.
- **Windows:** we recommend installing WSL, which gives you a Linux terminal inside Windows. Open PowerShell, run `wsl --install`, restart and open “Ubuntu” from the Start menu. Every exercise in the course is done in that terminal; if something is different, the lesson says so.

### 2. Run your first command

Copy this command, paste it into the terminal and press Enter:

<TryIt cmd={`echo "Hello, terminal"`} output="Hello, terminal">

`echo` prints back whatever you write after it. It does nothing else, but you've just given your first instruction in text.

</TryIt>

### 3. If something seems stuck

Some commands wait on purpose, like the servers we'll start in lesson 2. To stop them, press <kbd>Ctrl</kbd> + <kbd>C</kbd>. It works the same on macOS, Linux and WSL.
